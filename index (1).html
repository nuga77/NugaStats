Passo-a-Passo: Criar o Teu Site Online no GitHub

100% Gratuito e Permanente: Segue estes 5 passos simples para ficares com um link público (ex: https://oteunome.github.io/statgoal/) que podes abrir no telemóvel ou partilhar.
  1. Passo 1 - Guardar o Ficheiro no PC/Telemóvel:
    Clica no botão verde "Descarregar index.html" no topo desta aplicação. Vai guardar um ficheiro chamado exatamente index.html.
  2. Passo 2 - Criar Conta e Repositório no GitHub:
    Cria conta gratuita em github.com. Depois clica no botão "+" (canto superior direito) → "New repository".
  3. Passo 3 - Configurar o Repositório:
    Em Repository name escreve por exemplo statgoal. Deixa a opção Public selecionada e clica no botão verde Create repository.
  4. Passo 4 - Enviar o Ficheiro index.html:
    Na página seguinte, clica no link azul "uploading an existing file". Arrasta o ficheiro index.html que descarregaste e clica no botão verde "Commit changes" em baixo.
  5. Passo 5 - Ativar o Site (GitHub Pages):
    No menu de topo do teu projeto, clica em Settings (Definições) → na barra lateral esquerda clica em Pages → em Branch muda de "None" para main e clica em Save. Passado 1 minuto, atualiza a página e o teu link online aparece logo no topo!
